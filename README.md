# Agri

Project smart agriculture system yang terdiri dari web application (Next.js) dan machine learning service.

## Struktur Project

- **`Agrismart_man2/`**: Aplikasi Frontend & Backend berbasis Next.js (TypeScript, Tailwind CSS, Supabase).
- **`ml/`**: Machine Learning model dan API service (Python) untuk rekomendasi tanaman dan pupuk.

## Menjalankan Project

### 1. Web App (`Agrismart_man2`)
```bash
cd Agrismart_man2
npm install
npm run dev
```

### 2. Machine Learning API (`ml`)
```bash
cd ml
pip install -r requirements.txt
python main.py
```
